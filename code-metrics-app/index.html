Understanding Code Metrics

Lines of Code (LOC)

Counts actual code lines, excluding blank lines and comments. Helps measure code size and complexity.

Good: < 300 lines/file Warning: 300-500 lines Critical: > 500 lines

Cyclomatic Complexity

Measures the number of linearly independent paths through code. Higher values indicate more complex, harder-to-test code.

Good: 1-10 Warning: 11-20 Critical: > 20

Nesting Depth

Maximum depth of nested control structures. Deep nesting makes code harder to read and maintain.

Good: ≤ 3 levels Warning: 4 levels Critical: ≥ 5 levels

Comment Ratio

Percentage of comment lines to total lines. Good documentation improves code maintainability.

Low: < 10% Medium: 10-20% Good: > 20%

Docstring Coverage

Percentage of functions and classes with docstrings. Essential for API documentation.

Low: < 50% Medium: 50-80% Good: > 80%

Function Length

Average lines per function. Shorter functions are easier to understand, test, and maintain.

Good: < 20 lines Warning: 20-50 lines Critical: > 50 lines
